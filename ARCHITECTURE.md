# InkMap — архитектурный план

> Бесконечный холст для карт-мыслей (mind map), скетчей ручкой и файловых
> заметок. Веб-приложение: локальный FastAPI-бэкенд + ванильный JS-фронтенд.

---

## 1. Цели и назначение

- Рисовать интеллект-карты: ноды, рёбра, группы, заметки с уровнями.
- Ручка/маркер/карандаш/ластик поверх канваса («как в тетради»).
- Импорт Markdown-документов как карты: заголовки → дерево, чекбоксы → таски.
- Всё хранится локально (JSON + файлы картинок/аудио), без внешнего бэкенда.
- Один пользователь, один процесс, `127.0.0.1:8123`.

## 2. Технологический стек

| Слой | Технология |
|------|-----------|
| Бэкенд | Python 3.10+, FastAPI, uvicorn, pydantic |
| Фронтенд | Ванильный JS (ES-модули), HTML, CSS, SVG |
| Кисти | Canvas 2D, собственная математика (brushmath) |
| Хранилище | JSON-файлы карт в `data/`, бинарники в `data/images`, `data/media` |
| Тесты | pytest (бэкенд), `node --test` (фронт) |

Запуск: `run.bat` → `uvicorn server:app --host 127.0.0.1 --port 8123`.

## 4. Бэкенд — REST API (`server.py`)

| Метод и путь | Назначение |
|------|--------|
| `GET /api/maps` | список карт (имена без `.json`) |
| `POST /api/maps` | создать пустую карту |
| `GET/PUT/DELETE /api/maps/{name}` | читать / сохранить / удалить карту |
| `PUT /api/maps/{name}/rename` | переименовать файл карты |
| `POST /api/images` | загрузить картинку → `data/images/<uuid>.<ext>` |
| `POST /api/media` | загрузить голос/видео → `data/media/` |
| `POST /api/import-md` | **MD-файл → ноды/рёбра** (кнопка «Импорт MD») |

Именование карт: `sanitize_name` — без служебных символов Windows, без
зарезервированных имён (CON, COM1, …).

### Импорт MD (`/api/import-md`)

Кнопка «Импорт MD» в тулбаре → фронт шлёт файл → сервер парсит и возвращает
`{ nodes, edges, count, details, warnings }`. Обработка на сервере:

1. `parse_text` — заголовки H1–H4 строят дерево (стек по уровню), код-фенсы
   не ломаются, `---` вырезается, преамбула → заметка корня.
2. `make_task_nodes` — строки `- [ ]` / `- [x]` становятся дочерними таск-нодами.
3. `scan_images` + `attach_image` — `![alt](url)` из заметок:
   - `data:`-URI → декодируется;
   - `http(s)` → скачивается (таймаут 8 c, лимит 10 МБ);
   - локальный путь → **недоступен через кнопку**: предупреждение, текст цел.
   - Сохранённый файл живёт в `data/images/`, первая картинка → `image` ноды,
     её markdown вырезается из заметки.
4. `split_details` — заметки длиннее 450 символов режутся: краткое описание
   на ноде + дочерняя нода «Детали».
5. `assign_ids` — детерминированный id `n_<md5-8>` от пути заголовков.
6. `set_collapse` + `layout` — tidy-tree: поддерево каждого родителя непрерывно,
   родитель центрирован над своими детьми (`check_overlaps` + `validate` обязательны).
7. Любая ошибка валидации → HTTP 400 с деталями.

Файл в `tools/mindmap_export.py` — консольная обвязка того же ядра для
проекта TwitchBot: фиксированные пути, overlay `MINDMAP.md`, `--sync`
(перенос статусов тасков из карты обратно в MD), `--dry-run`.

## 5. Фронтенд — модули (`static/js/`)

| Модуль | Ответственность |
|--------|----------------|
| `store.js` | единственный источник данных: `state {nodes, edges, strokes, shapes, reveal, meta}`; `normNode`, подписка `subscribe`, undo-хуки, flush-хук автосейва |
| `view.js` | камера: pan/zoom у курсора, `screenToWorld`, подписки на смену вида |
| `nodes.js` | рендер нод (DOM), уровни заметок, свёртка ▸N, мета-строка тасков/тегов, картинки, аудио |
| `edges.js` | кубические рёбра, стороны привязки, скрытие свёрнутых поддеревьев, клики по рёбрам |
| `ink.js` | режимы рисования, настройки кистей, undo инка, группы штрихов/фигур |
| `brushmath.js` | EMA, velocity/pressure, превью толщины, refineStroke, paths |
| `input.js` | мышь/клавиатура, selection, marquee, drag, клики по нодам |
| `shapes.js` | фигуры rect/ellipse/arrow, hit-тест |
| `history.js` | undo/redo стеки (подписка на store) |
| `search.js` | поиск нод, центровка |
| `minimap.js` | миникарта, contentBounds, fit-transform |
| `nodepanel.js` | правая панель редактирования выбранной ноды |
| `quick.js` | «быстрые мысли» (Ctrl+Enter) и childrenCount |
| `io.js` | экспорт JSON, импорт JSON, **импорт MD**, drag&drop / вставка картинок |
| `api.js` | fetch-обёртки над REST |
| `banner.js` | всплывающие уведомления |
| `voice.js` | MediaRecorder → `/api/media` |
| `theme.js` | тёмная/светлая тема + фон канваса (точки/линии/сетка/plain) |
| `palette.js` | палитра цветов |

Поток данных однонаправленный: события → `store` мутации → `emit()` →
перерисовка подписчиков (`renderNodes`, `renderEdges`, миникарта). Автосейв —
debounce через `flush`-обработчик в `main.js`.

## 6. Модель данных — формат файла карты

```jsonc
{
  "version": 1,
  "meta": { "source": "…", "generator": "…" },
  "nodes": [ /* см. ниже */ ],
  "edges": [{ "id": "e_…", "from": "n_…", "to": "n_…", "fromSide": "auto",
              "toSide": "auto", "label": "", "dashed": false, "arrow": true }],
  "strokes": [{ "id": "s_…", "points": [[x,y],…], "color": "#…", "width": 2.5,
                "style": "pen|pencil|marker|highlighter", "widths": [25.5,…] }],
  "shapes": [{ "id": "q_…", "type": "rect|ellipse|arrow", "a": [x,y], "b": [x,y],
               "color": "#…", "width": 2.5 }],
  "reveal": 1
}
```

Поля ноды (`normalizeState` легализует всё при загрузке):

`id, x, y, title, note, levels[{id,text,pin}] (до 5), color, image, audio,
glowMode(off|glow|outline), isGroup, isText, isImage, font(plain|hand),
groupId, w, h, collapsed, tags[≤8, lowercase], isTask, done`.

Отдельные типы нод:
- **обычная** — заголовок + заметки-уровни;
- **isGroup** — прямоугольная рамка (под нодами), сворачивается;
- **isText** — свободный текст без подложки;
- **isImage** — картинка, масштаб за угол, `image` = `/images/<uuid>.<ext>`.

## 7. Ключевые механики

### Сворачивание поддерева (tree-fold)
`store.computeHiddenIds` — BFS от каждой свёрнутой ноды: потомки по рёбрам
прячутся транзитивно (`display:none`). Бейдж «▸N» на свёрнутой ноде показывает
число скрытых. Скрытые не участвуют в кликах, marquee, поиске и миникарте.

### Таски и теги (подход «минимальное ядро»)
- `isTask` + `done` + `tags[]` в модели ноды.
- Мета-строка на ноде: чекбокс (done), чипы `#тег`, кнопка `+` (prompt).
- Клик по чипу — фильтр `setTagFilter`: чужие ноды гаснут (`.node-dim`).
- `done` → зачёркнутый заголовок.
- `--sync` в CLI флипает `[ ]↔[x]` в исходных MD по стабильному ключу
  (цепочка заголовков + нормализованный текст таска).

### Кисти (зафиксированный движок)
`pen/pencil/marker` — вариативная толщина: EMA на скорость/давление →
заполненный контур (`variableOutline`, width s массивом `widths`).
`highlighter` — равномерный штрих. Конвейер:
`EMA → интерполяция → refineStroke (midpoint-Q, ±2, ease 0.4) → strokeRing → path`.

### Статусные цвета импорта
`✅ #d9f5ce` факт · `🔨 #ffe9b8` в работе · `📌 #cfe4ff` закреплено ·
`💡 #e4dbff` идея; без маркера — правило раздела (11/«ограничения» → синий).

## 8. Тестирование

- **Бэкенд** (`pytest tests -q`): `test_api.py` — REST; `test_import_md.py` —
  endpoint (таски, «Детали», картинки в проект, предупреждения, валидация);

## 9. Известные проблемы / бэклог

- Относительные пути картинок в MD недоступны через кнопку (браузер шлёт
  только .md) — только предупреждение; решение: выбор папки/архив.
- 13 «битых» ссылок картинок в личных картах `думать-какать.json`,
  `мысли.json` — файлы удалены, узлы живы; UI показывает заглушку
  `.img-broken`, зачистка ручная.
- Детерминированные id импорта конфликтуют при повторном импорте того же файла
  — фронт перегенерирует коллизии и честно пишет «Импортировано N» (факт,
  а не серверный count).
- `npm test` недоступен из-за PowerShell policy — вызывать `node --test`
  напрямую.
